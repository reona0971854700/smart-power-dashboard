1. ==專案名稱{
    # 智慧建築能源管理系統
    這是一個用於監控指定建築物下的各項設備用電狀況的儀表板，
    並加入了歷史用電查詢功能及設備管理介面。
}

2. ==功能介紹{
    # -設備用電儀表板
    # -歷史查詢功能
    # -新舊設備管理系統
    # -使用者帳號&密碼管理設置
    # -並以視覺化圖表分析
}

3. ==技術使用{
    # 前端技術{
        -Vue.js
        -Javescript
        -ECharts   
        -HTML、CSS
    }
    # 後端技術{
        -Node.js
        -RESTful API
        -SQL server
        -Vite
        -JSON
    }
}

5. ==安裝與執行{
    ## 安裝&執行方式{
        1. 開啟系統終端機
        2. git clon https://github.com/reona0971854700@gmail.com/
           smart-power-dashboard.git
        3. cd smart-power-dashboard
        4. npm install
        5. node server/index.js
        6. 再次開啟新的終端機
        5. cd smart-power-dashboard
        6. npm run dev
    }
